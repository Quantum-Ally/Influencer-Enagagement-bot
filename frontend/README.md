# Influencer Engagement Bot - Frontend

Modern React frontend with glassmorphism UI for the Influencer Engagement Bot.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Create a `.env` file (optional, defaults to http://localhost:5000):
```bash
VITE_API_URL=http://localhost:5000
```

3. Run the development server:
```bash
npm run dev
```

The frontend will run on port 3000 by default.

## Build for Production

```bash
npm run build
```

## Features

- **Send Email Page**: Beautiful form with glassmorphism effects to send emails to influencers
- **Sent Emails Dashboard**: View all sent emails with filtering and search capabilities
- **Modern UI**: Apple-inspired liquid glass aesthetic with smooth animations
- **Responsive Design**: Works on desktop, tablet, and mobile devices
